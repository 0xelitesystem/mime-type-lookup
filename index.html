MIME Type Lookup

Extensions and media types, both ways

Type a file extension (like .webp) to find its MIME type, or type a MIME type to find matching extensions, or free-text search across everything. Around 200 common types are built in. Nothing leaves this page.

All lookups run locally from a built-in table. No network requests are made.
